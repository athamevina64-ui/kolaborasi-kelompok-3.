Jawaban LKPD Matematika SPLDV

Berdasarkan Iklan Mutia Stor

1. Menentukan Variabel

Misalkan:
x = Harga 1 jam CD
y = Harga 1 kipas

2. Membuat Model Matematika

Paket 1:

5x + 7y = 650.000

Paket 2:

7x + 5y = 550.000

3. Menentukan Harga Masing-Masing Produk

Metode Eliminasi:

5x + 7y = 650.000 | × 7
7x + 5y = 550.000 | × 5

35x + 49y = 4.550.000
35x + 25y = 2.750.000
------------------------ -
24y = 1.800.000
y = 1.800.000 / 24
y = 75.000

Mencari nilai x:

5x + 7y = 650.000
5x + 7(75.000) = 650.000
5x + 525.000 = 650.000
5x = 650.000 - 525.000
5x = 125.000
x = 125.000 / 5
x = 25.000

Jadi, hasilnya adalah:

  • Harga 1 jam CD = Rp25.000
  • Harga 1 kipas = Rp75.000

4. Kesimpulan

Berdasarkan perhitungan menggunakan metode eliminasi dan substitusi, diperoleh harga satu jam CD sebesar Rp25.000 dan harga satu kipas sebesar Rp75.000. Dengan demikian, SPLDV dapat digunakan untuk menentukan harga masing-masing produk berdasarkan dua paket penjualan.
