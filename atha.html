Jawaban LKPD Matematika SPLDV

Berdasarkan Iklan CycleSmart

1. Menentukan Variabel

Misalkan:
x = Harga 1 jam dinding
y = Harga 1 lampu hias

2. Membuat Model Matematika

Paket 1:

3x + 5y = 290.000

Paket 2:

5x + 3y = 240.000

3. Menentukan Harga Masing-Masing Produk

Metode Eliminasi:

3x + 5y = 290.000 | × 5
5x + 3y = 240.000 | × 3

15x + 25y = 1.450.000
15x + 9y = 720.000
------------------------ -
16y = 730.000
y = 730.000 / 16
y = 45.625

Mencari nilai x:

3x + 5y = 290.000
3x + 5(45.625) = 290.000
3x + 228.125 = 290.000
3x = 290.000 - 228.125
3x = 61.875
x = 61.875 / 3
x = 20.625

Jadi, hasilnya adalah:

  • Harga 1 jam dinding = Rp20.625
  • Harga 1 lampu hias = Rp45.625

4. Kesimpulan

Berdasarkan perhitungan menggunakan metode eliminasi dan substitusi, diperoleh harga satu jam dinding sebesar Rp20.625 dan harga satu lampu hias sebesar Rp45.625. Dengan demikian, SPLDV dapat digunakan untuk menentukan harga masing-masing produk berdasarkan dua paket penjualan.
